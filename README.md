# VOLTRIX Hub

Your own version of Logitech G Hub. Windows app, starting with the Logitech PRO keyboard.

Status: v0.1.0 pre-release. The window and navigation only. No hardware yet.

Build: run `build.bat` on Windows. No extra installs needed. It makes `VOLTRIX-Hub.exe`.

Method and plan: see the project plan and the build method file.
