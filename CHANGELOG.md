# Changelog

## v0.1.0 pre-release: First light

- App window with the VOLTRIX look and a sidebar (Devices, Profiles, Updates, Settings).
- Devices page with a PRO keyboard card and a greyed G502 HERO card. Preview data only.
- Device page shell with a back button and Lighting, Assignments and Game Mode tabs (empty for now).
- Tray icon with Open and Exit. Minimise sends the app to the tray.
- Only one copy of the app can run at a time.
- Version shown in the sidebar and the window title.
- No hardware is touched yet.
